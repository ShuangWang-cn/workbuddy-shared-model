# 使用说明

> 本文是**面向使用者**的说明。开发者信息请看 `src/` 里的代码与提交记录。

---

## 一、它能做什么

把你的 **WorkBuddy 额度**接到别的 AI 软件上用。

- 原来只能在 WorkBuddy 自己的界面里花的积分，现在可以在 DeepSeek Harness、
  OpenCode 等你常用的 AI 软件里用。
- 原理是本工具在你**本机**读出已登录的 WorkBuddy 账号凭据，
  换成一份配置资料，再交给你（或你的 AI 助手）写进目标软件。
- **所有解析都在你自己电脑上完成**，不经过任何第三方服务器。

---

## 二、使用前须知

### 1. 需要管理员权限

双击运行 exe 时，Windows 可能弹一次「需要管理员权限」，**请点「是」**。

> 原因：WorkBuddy 是 Electron 程序，读取它的登录凭据需要系统级授权，这是无法绕过的。
> 想一劳永逸：右键exe → 属性 → 兼容性 → 勾选「以管理员身份运行此程序」。

### 2. 先把 WorkBuddy 客户端登录好

本工具读的是**你本机 WorkBuddy 已登录的账号**。
如果客户端没登录或换了账号，请先在WorkBuddy 里登录成功，再回来点解析。

### 3. 账号换了、过期了怎么办

界面上的「有效期」会显示凭据的到期时间。到期或换号后，
**重新点一次「开始解析」** 就行，工具本身不用更新。

## 三、四步用法

### 第 1 步 · 双击运行

双击 `workbuddy共享模型.exe`（如果你下载的是源码，需要先按README 编译）。

### 第 2 步 · 点「开始解析 WorkBuddy」

点一下按钮，约半秒出结果。界面会显示：

- 账号信息
- 接口地址
- 凭据有效期
- 可用模型清单（带积分倍率，按倍率从低到高排序）

> 这些数字是**现场从官方接口拉取的实时值**，不是预置的。
> 模型数量、倍率都可能随官方调整而变化。

### 第 3 步 · 选目标软件，复制说明

界面上方有标签页：

| 标签页 | 选它当你要配置的是 |
|---|---|
| **DeepSeek Harness** | DeepSeek Harness（装插件，免常开本工具） |
| **OpenCode** | OpenCode（写配置文件，直连） |
| **通用** | 其他软件（Cursor、Cline、Cherry Studio、自写程序等） |

**如果你的目标软件不在上面两栏，就用「通用」标签页**——
它给出的是字段表（API 地址填哪、Key 填哪、模型名填哪）和常见报错对照，
适合任何"填地址 + Key"型的软件。

选中标签页后点「**复制全文**」。

### 第 4 步 · 交给 AI 助手执行

把刚复制的文本粘贴给对话里的 AI 助手（比如 WorkBuddy、Claude、ChatGPT）。

它会照着说明把配置写好，并且**实际发一次请求**来验证。
正常的返回会包含 HTTP 状态码和返回内容。

> 建议的验证提示语（可以一起发给它）：
> 「配置完请真发一次请求，把状态码和返回前几十个字报给我，不要只说『配置成功』。」

## 四、常见问题

### Q1：一定要一直开着这个工具吗？

**看你在用什么软件**：

| 情况 | 需要常开吗 |
|---|---|
| DeepSeek Harness 装了配套插件 | **不需要** |
| OpenCode 等填了官方地址 | **不需要** |
| 配置时填的是本地桥地址（`127.0.0.1:18791`） | **需要**，关掉就断 |

### Q2：安全吗？会泄露账号吗？

- 解析全部在**你本机**完成，不上传任何数据。
- 生成的配置文件里**含你的凭据**，所以：
  - ✅ 可以放心在自己的电脑上用
  - ❌ **不要**把配置文件发给别人
  - ❌ **不要**把它提交到 GitHub 等公开平台

### Q3：模型列表里的「×0.06」是什么意思？

**积分倍率**。调用这个模型时，按它的倍率消耗积分。数字越小越省。
工具默认按倍率从低到高排序，第一个通常最划算。

### Q4：为什么模型数量会变？

模型清单由官方下发，官方随时可能增删模型、以调整模型范围和倍率。
工具每次解析都是重新拉的，所以你会看到数量变化——这是正常的。

### Q5：报「模型不存在」/「404」

- 确认填的接口地址**只到 `/v2`**，不要多带 `/chat/completions`。
- 确认模型名用的是清单里**一模一样的 id**（不是显示名）。
- 部分软件要求接口必须为流式。

### Q6：报 401 / 鉴权失败

- 重新点一次「开始解析」（凭据可能过期或账号变了）。
- 检查 Key 前后有没有多带空格或换行。

### Q7：报 429

**这不是错误**，是该模型当前被限流了。换个模型试试即可，鉴权是通过的。

### Q8：界面打不开 / 空白

- 确认文件解压完整（不要只拷单个 exe）。
- 用系统自带浏览器打开方式异常时，请提issue。

### Q9：一定要管理员权限吗？

见「二、使用前须知」第 1 条。

## 五、卸载

1. 删除 exe 文件（如果是编译的，删掉 `dist/`）。
2. DeepSeek Harness：删除插件目录，并在其 `package.json` 里移除对应登记。
3. 清理凭据文件：删除 `.wbbuddy` 目录（如果用过）。
4. 其他软件：把配置文件里新增的那段删掉即可。
